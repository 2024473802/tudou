# 武侠土豆兄弟 (Wuxia Potato Brothers)

一个武侠风格的Roguelike自动战斗游戏，灵感来自Brotato（土豆兄弟）。

## 游戏特色

🎮 **游戏玩法**
- 类Brotato的自动战斗Roguelike游戏
- 使用WASD或方向键移动角色
- 角色自动攻击附近的敌人
- 每波结束后进入商店购买装备

⚔️ **武侠元素**
- 三种门派可选：剑客、少林僧、刺客
- 多种武侠武器：青龙剑、屠龙刀、降龙十八掌等
- 武侠技能升级：九阳神功、凌波微步、独孤九剑等
- 武侠风格敌人：山贼、刺客、魔教弟子等

🏆 **游戏目标**
- 击败每波敌人，生存尽可能长的时间
- 收集金币，购买武器和道具
- 升级角色，变得更强大

## 如何运行

### 方式一：直接打开
直接在浏览器中打开 `index.html` 文件即可游玩。

### 方式二：使用本地服务器
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx serve .
```
然后在浏览器中访问 `http://localhost:8000`

## 控制方式

| 按键 | 功能 |
|------|------|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |

## 游戏系统

### 角色系统
- **剑客**：攻击力+10%
- **少林僧**：生命值+20%
- **刺客**：移动速度+15%

### 武器系统
| 武器 | 伤害 | 攻速 | 范围 | 描述 |
|------|------|------|------|------|
| 青龙剑 | 12 | 1.0 | 80 | 锋利的长剑，攻击迅速 |
| 屠龙刀 | 25 | 0.6 | 100 | 沉重的大刀，伤害极高 |
| 血影匕首 | 8 | 2.0 | 50 | 快如闪电的匕首 |
| 铁扇公主扇 | 15 | 1.2 | 120 | 可远程攻击的铁扇 |
| 齐天棍 | 18 | 0.8 | 90 | 攻击范围广的长棍 |
| 穿云弓 | 14 | 0.7 | 200 | 远程攻击，射程极远 |
| 降龙十八掌 | 20 | 1.5 | 60 | 以气御敌的拳法 |
| 暗器飞针 | 6 | 3.0 | 150 | 连续发射的暗器 |

### 升级系统
升级时可以选择以下技能之一：
- 铁布衫：+25 最大生命
- 九阳神功：+15% 攻击力
- 凌波微步：+12% 移动速度
- 独孤九剑：+20% 攻击速度
- 易筋经：每秒回复3点生命
- 金钟罩：减少10%受到的伤害
